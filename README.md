# Catálogo Interactivo de Películas

Aplicación web interactiva desarrollada en React, Vite y Tailwind CSS como parte del parcial / laboratorio de desarrollo web. Permite explorar un catálogo de películas, buscar en tiempo real, aplicar filtros combinados, guardar favoritas, ver detalles en un modal y calificar películas de 1 a 5 estrellas.

---

## Tecnologías Utilizadas

- **React** (Componentes, Props, Estados con useState)
- **Vite** (Entorno de desarrollo y empaquetador)
- **Tailwind CSS** (Estilos utilitarios)
- **JavaScript (ES6+)** (map, filter, destructuring)

---

## Instrucciones para Ejecutar el Proyecto

Sigue estos pasos en la terminal para instalar, abrir y ejecutar la aplicación en tu máquina local:

1. **Clonar el repositorio:**
   ```bash
   git clone <https://github.com/dannasofiacruz14-byte/parcialsegundocorteweb.git>

Verificar directorios y navegar a la carpeta del proyecto:
Al clonar el repositorio, la terminal se ubicará en la carpeta raíz. Para ejecutar los comandos de Node.js y React, debes ingresar a la subcarpeta my-app donde se encuentran los archivos de la aplicación:

# Listar los archivos y carpetas del repositorio para verificar la estructura:
ls

# Entrar a la subcarpeta del proyecto de React:
cd my-app

Instalar las dependencias:

npm install
Iniciar el servidor de desarrollo y generar el Localhost:

npm run dev
Abrir en el navegador:
Copia el enlace del Localhost que muestra la terminal (por ejemplo: http://localhost:5173/) y ábrelo en tu navegador para interactuar con la aplicación.
